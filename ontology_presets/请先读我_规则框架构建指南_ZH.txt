--------------------------------------------------------------------------------
一、 核心设计理念：极简学术三要素原则
--------------------------------------------------------------------------------
在传统图谱软件中，用户往往需要手动配置复杂的节点颜色、图标、几何形态以及冗长的扁平规则列表。
在本项目中，我们全面推行“极简三要素”科研规范：

1. 每一个实体分类（entity_categories）仅需且必须保留三项核心内容：
   (1) 名称：name（中文名称）与 en_name（英文名称）
   (2) 描述：description（中文学术定义）与 en_description（英文学术定义）
   (3) 正则模式：patterns（精准的正则表达式字符串列表）

2. 全面剔除 Emoji 与表情符号：
   严格对齐 Cytoscape、Gephi、NCBI 等国际经典科研工具规范，不再在 JSON 中声明 "icon" 字段。

3. 视觉色彩与形态由图表生成引擎自动分配：
   无需也不要在 JSON 中声明 "color" 或 "shape" 属性！
   图表引擎内置了经典学术期刊（Nature/Science 风格）的专业调色板与几何形态库：
   - 实体节点颜色池：深蓝(#2563eb)、琥珀黄(#d97706)、深红(#dc2626)、墨绿(#059669)、稳重紫(#7c3aed)、蓝青(#0891b2)、珊瑚橙(#ea580c)、洋红粉(#db2777) 等
   - 实体几何形态池：dot (实心圆), diamond (菱形), square (正方形), triangle (三角形), hexagon (六角形), star (星形), box (方块), triangleDown (倒三角)
   - 引擎将严格按照您在 JSON 中编写各分类的先后顺序，自动循环赋予和谐且差异明显的颜色与几何形态。
   - 特殊兜底类别 "Uncertain"（无法判断/待定）由系统锁定分配中性灰度色(#9ca3af)与椭圆(ellipse)。

4. 关系机制分类（relation_categories）：
   同样仅需包含 name/en_name 以及 description/en_description，边连线色彩由引擎机制色谱自动分配。

二、 正则表达式 (patterns) 编写最佳实践与范例
--------------------------------------------------------------------------------
第零阶规则过滤引擎（RulePreFilter）采用高效的数据驱动模式，不消耗任何大模型 Token，
能在毫秒内极速识别出具备标准命名法特征的生物医学实体。

系统在执行正则匹配时默认开启【忽略大小写 (re.IGNORECASE)】，因此您无需重复列举大小写。

【典型编写范例】：
1. 词干/词缀结尾匹配（使用 .* 配合词尾 $）：
   - 激酶/受体类蛋白：".*(?:kinase|receptor|synthase|polymerase)$" 或 ".*(?:激酶|受体|合成酶)$"
   - 小分子靶向药物词缀（INN 国际非专利药品名称命名规范）：
     ".*(?:tinib|rafenib|lisib|ciclib|parib|zomib|statin|prazole|sartan|dipine)$"
   - 单抗与 ADC 生物制品：".*(?:mab|cept|vedotin|deruxtecan)$" 或 ".*(?:单抗|抗体)$"
   - 疾病与病理表型后缀：".*(?:itis|oma|carcinoma|sarcoma|syndrome|disease)$" 或 ".*(?:炎|癌|瘤|综合征)$"

2. 精确全称或首字母缩写集合（使用 ^ 和 $ 锚定）：
   - 核心明星基因列表："^(?:TP53|EGFR|KRAS|MYC|STAT3|AKT1|MTOR|BRAF|PIK3CA|PTEN)$"
   - 关键免疫检查点："^(?:PD-1|PD-L1|CTLA-4|LAG-3|TIM-3|TIGIT|4-1BB|OX40)$"
   - 经典内源代谢物："^(?:ATP|ADP|AMP|GTP|CAMP|NADH|NADPH|ROS|NO|GLUCOSE|LACTATE)$"

3. 规范化前缀匹配：
   - 非编码 RNA 命名："^(?:mir|mirna|microrna|lncrna|circrna|sirna)[-_].*"

4. 序列突变与变异位点：
   - 蛋白质单氨基酸置换突变（如 p.T790M, L858R）："^p\\.[a-z]\\d+[a-z]$" 或 "^[a-z]\\d+[a-z]$"
   - 基因组 SNP 编号（如 rs123456）："^rs\\d+$"

【JSON 转义避坑要点】：
- 在 JSON 字符串中，反斜杠 "\" 属于转义控制字符。因此正则表达式中的原生反斜杠（如 \\d、\\.、\\+）
  必须写成双反斜杠 "\\\\"。
  例如：匹配 "p.T790M" 应写为 "^p\\.[a-z]\\d+[a-z]$"；
        匹配带正电荷离子 "Ca2+" 应写为 ".*ca2\\+.*"。

四、 快速测试与生效指南
--------------------------------------------------------------------------------
1. 在本目录新建您的 `.json` 文件并保存（确保格式为合法 JSON，无多余逗号）。
2. 返回 Web 界面图谱分析工作台，点击配置区的【🔄 刷新列表】按钮（或直接刷新浏览器）。
3. 在“选择标准预设方案”下拉框中，您将看到您自定义的标准名称。
4. 选中后点击【🚀 启动分级研判流水线】，系统将严格按照您配置的 patterns 与三要素规范自动展开分析！
